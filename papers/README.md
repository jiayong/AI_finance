## 1. FactorBench

### 它解决的问题

传统因子挖掘只报 IC 或单因子回测，忽略三件事：

1. **因子之间高度共线** —— 单独 IC 高的因子，和已有因子一起用时可能毫无增量
2. **因子可能只是风格的重新包装** —— 动量因子可能等价于「买高波动率」
3. **单因子有效 ≠ 组合有效** —— 组合效用取决于相关结构，不取决于单个 IC

因此它把评估拆成四层，逐层加严。

### 与本项目代码的对应

| 论文概念 | 代码位置 |
|---|---|
| 面板 `(date, asset)` MultiIndex | `factorbench_adapter.py: to_panel()` |
| `FIELDS` 八个标准字段 | `factorbench_adapter.py: FIELDS` |
| IC 表 | `run_factorbench_eval.py: stage_ic()` |
| 风格中性化（5 种风格） | `stage_style()`，`STYLES=['beta','volatility','momentum','reversal','liquidity']` |
| 冗余（Spearman 相关） | `stage_redundancy()` |
| 组合效用 | `stage_portfolio()` + `backtest_hetero.py` |
| `MIN_OBS_PER_DATE=30` | 截面最少 30 只票，否则整日不作 IC / 回归 |
| `WINSOR=(0.01,0.99)` | 逐日横截面缩尾 |
| `HAC_LAGS=25` | Newey-West 滞后阶数 |

### 与本项目最大的口径差异

| 项 | 论文 | 本项目 |
|---|---|---|
| 收益口径 | **原始收益** | 默认**超额收益**（`NetReturn{H} = FutureReturn{H} − SPYReturn{H}`） |
| 数据字段 | 完整 OHLCV +市值 | 仅 Close / Volume，其余派生（见 `DATA_GOVERNANCE.md` §6.1） |
| universe | 动态成分 | **静态 50 只大盘股**，回填到 2010 年（幸存者偏差） |

第一条影响最大：超额化会扣掉 β≈1 大盘股的市场成分，因子 IC **机械性变小**。
所以必须用 `--target net` 与 `--target raw` 各跑一次，才能和论文对齐。
后两条决定了本项目的结论只能读作「这 50 只票上的相对排序」，
不能读作「策略的绝对收益」。

## 2. Chen & Welch (2026), *What Useful Alphas?*

arXiv:2607.06502v1（2026-07-08 draft，目标期刊 FAJ）。
样本约 200 个多空异象，来自 Chen & Zimmermann (2022) 的复制库。

### 核心实证事实

多空组合月均收益（中位数）：

| 样本 | 截至 2005 | 2005 之后 |
|---|---|---|
| 全部股票 | 48 bp | **19 bp** |
| 剔除最小 10% 后 | 26 bp | **7 bp** |

中位 t 统计量 **0.45**；中位 CAPM alpha **9 bp**；中位 Sharpe **0.11**。

即：**异象收益的绝大部分在 2005 年后消失了**，剩下的部分在可交易的大盘股上
几乎归零（7 bp/月）。

### 经验贝叶斯收缩公式

这是本项目直接采用的部分：

```
r_adj = [1 − 1/Var(t)] × r
```

`Var(t)` 是全部因子 t 统计量的**横截面方差**，1 代表「纯噪声」的基准。
`Var(t)=1.09` 时，信号的占比只有 **8%**。

直觉：如果 200 个因子的 t 值方差接近 1，那它们看起来的分散度几乎全是抽样噪声，
真实信号极少——因此要把每个估计值大幅收缩。

### 我们复现时的关键发现

在本项目 4 个因子上套这个公式，得到：

| `Var(t)` 估计方式 | 数值 | 推出的信号占比 |
|---|---|---|
| 从 HAC t 值算 | 2.290 | 56.3% |
| 从非重叠样本算 | 0.539 | **0%** |

**两个估计器严重冲突**，差 4 倍以上。这不是可以二选一的问题——
正确读法是**证据不足**，绝不能挑好看的那个。

原因：论文的 `Var(t)` 来自约 170 个异象，横截面方差估计很稳；
本项目的 4 个因子给出的方差估计噪声极大，**根本不具备套用该公式的样本量**。

这一条是本项目最诚实的结论之一，代码在 `eb_shrinkage.py`（会把两种估计并列打印，
不隐藏分歧）。

### 长期与短期的不对称

`long-minus-market` 的 `Var(t)=0.98 < 1`，意味着**多头端的调整后均值全部为 0.00**。
存活因子（如 cash-based operating profitability）的收益**几乎全部来自空头端**。

推论：在只做多、且有做空限制的市场里，这些 alpha 基本不可用。

### 成本量级

| 项 | 数值 |
|---|---|
| 异象组合持仓的买卖价差 | 约为 NYSE 中位数的 **4 倍** |
| 单腿月换手 | 约 **40%** |
| 25 bp 半价差下的往返成本 | 约 **20 bp/月** |
| Chen & Velikov (2023) 净收益 | **−1 bp/月**；用成本最优执行后 **+4 bp/月** |
| 组合 250–380 bp 毛收益 | 净 **0–20 bp** |

这条直接支撑了本项目 `--cost-model liquidity` 的设计动机：**统一 bps 假设是错的**，
成本必须按流动性逐股定价。实测结果见 `FACTORBENCH_README.md` §7.4。

## 3. 两篇论文合起来对本国项目的判断

| 证据 | 来源 |
|---|---|
| 本项目 4 个因子中，只有 `Volatility20` 通过 Driscoll-Kraay 检验（t=3.30） | `hac_inference.py` 实测 |
| `Volatility20` 同时是**成本最贵**的因子（成本倾斜 +0.625） | `cost_model.py` 实测 |
| 大盘股是最严苛的检验格，与论文「剔除小盘后 7 bp」的结论一致 | Chen & Welch |
| 静态 universe 让一切偏乐观 | 本项目自身的偏差 |

**合起来的读法**：唯一统计上站得住的因子，恰好是交易成本最高的那个。
这两个事实必须一起看——单独看任何一个都会得出错误结论
（「它最稳健」或「它太贵了」都不完整）。
